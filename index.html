This browser is not supported

Unicode Art needs both WebGPU and WebAssembly. There is no fallback. Please use a browser with WebGPU enabled, such as a current version of Chrome or Edge.

    Unicode Art

    Turn an image into text made from the characters of your fonts.

    Image

    Or paste an image anywhere on the page (Ctrl+V), or drop one here. A new image replaces the current one.

    Fonts

      Drag to reorder. A character missing from a font is looked up in the fonts below it; characters no font has are never used.

      Options

      A cell is the width of the digit 0 in the font stack. Lines never exceed the max width; the height follows the image. By default bright areas get dense characters, as the output is light text on black.

      Status

      Add a font and an image to begin.
